# تحسين

> يحوّل تقرير Google PageSpeed Insights إلى خطة تنفيذ عربية مرتبة.

## المسار

`رابط الموقع → تقرير الجوال وسطح المكتب → قواعد Lighthouse → خطة عربية → Markdown أو PDF`

## المزايا

- تحليل Performance وAccessibility وBest Practices وSEO.
- مقارنة الجوال وسطح المكتب.
- قواعد عربية لمشاكل الصور والموارد وJavaScript وCSS والتخزين المؤقت والوصول وSEO.
- ترتيب حسب الأولوية والأثر.
- تصدير Markdown وطباعة PDF.
- لا يُحفظ مفتاح API أو نتائج المواقع.

## التشغيل

افتح `index.html` وأدخل رابط الموقع ومفتاح Google PageSpeed API عند الحاجة.
